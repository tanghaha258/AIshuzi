# P6 课后报告 2.0：证据链评价与可导出诊断

## 背景

P5 教师摄像头识别由于当前设备没有摄像头，先暂停硬件体验验证。P6 转向课后报告落地，把“完成试讲后给一段总结”升级为可复盘、可追溯、可导出的评价报告。

## 目标

- 报告必须基于课堂事件、AI学生反应、即时教学建议和教师观察事件生成。
- DeepSeek 配置可用时，报告诊断走真实模型；未启用或调用失败时，清晰降级到本地规则诊断。
- 报告不只展示分数，还要展示证据链、关键时间线、学生响应诊断、教师策略命中和改进建议。
- 报告数据保存到 SQLite，刷新和重启后仍可查看。
- 报告内容生成 Markdown 和 HTML，先提供复制导出能力，后续 Electron 阶段可接文件导出。
